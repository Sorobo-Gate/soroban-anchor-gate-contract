# Security Policy

## Audit Status Disclaimer
This software is currently in active pre-production development and has not yet undergone a formal third-party cryptographic or smart contract audit. Do not deploy these contracts to Stellar Mainnet with real capital without independent verification.

## Reporting a Vulnerability
If you discover a potential security vulnerability within this repository, please report it privately:
* **Contact:** security@sorobananchorgate.io (or via maintainer direct message on Telegram)
* Please provide a proof-of-concept and reproduction steps.
* Do not disclose the vulnerability in public GitHub issues or pull requests until a fix has been published.
